# AI Video Library · AI 视频资料库

开源整理的 **AI 视频 / 生图提示词原文**，附写法方法论、术语速查和成片对照样例。库内只收提示词（不要求有成片）；`cases/` 中已有的成片样例作为参考保留。

## 先逛逛：技巧锦囊

不知道该搜什么的时候，从 **[INDEX.md 最上方的「技巧锦囊」](INDEX.md)** 开始翻。这里收的是「想不到要问、但能给人新思路」的技巧，例如用力场让特效和画面融合、用一镜到底拍打斗、用混合风格做出电影感。每条都有一句「技巧钩子」（巧在哪）和「触发场景」（什么时候用得上）。

- 专门的新条目放在 `prompts/技巧锦囊/`；其他分类里符合条件的条目保留原分类，只加标签 `技巧锦囊` 交叉收录。说明见 `prompts/技巧锦囊/README.md`。

## 目录结构

| 路径 | 内容 |
|------|------|
| `prompts/<中文分类>/` | 按中文分类归档的提示词原文。每个文件的结构：标题 → 来源概述（非原文）→ 条目 → 总结（非原文） |
| `cases/<中文分类>/<样例>/` | 成套对照样例：`prompt/prompt.txt`（原文）+ 成片说明 + 来源记录 |
| `skills/` | 从原文提炼的写法 skill（策展者整理，非原文） |
| `docs/` | 规范、术语、最佳实践、策展日志、抓取失败记录 |
| `INDEX.md` | 给人看的索引：分类 → 条目（一行描述 + 标签） |
| `index.jsonl` | 给 AI / 程序用的索引：每行一条，含全部元数据与完整原文 |
| `scripts/build_index.py` | 从 Markdown 重新生成 `INDEX.md`、`index.jsonl` 和 `prompts/README.md` 的统计 |

分类说明与各分类条目数见 `prompts/README.md`。

## 条目格式

每条计数的提示词都是「一个 `yaml` 元数据块 + 紧跟的 `text` 围栏」：

- `text` 围栏里是**完整原文，逐字不改**（不润色、不翻译、不补全）。只有在对照原始出处证明是转录错误时才更正，更正记录在元数据「核对说明」和 `docs/CURATION-LOG.md`。
- 元数据字段：id、标题、原标题、分类、标签、适用模型、语言、来源链接、镜像、作者、发布日期、热度、许可、原文类型、核对状态、核对说明、完整性、备注，以及可选的技巧钩子、触发场景（用于技巧锦囊，其他条目留空）。
- 不含计数提示词的讲解类文件（教程视频的文案、字幕）在「来源概述」开头放一个「文件元数据」块，字段相同。
- 标记为「非原文」的内容（来源概述、总结、策展备注、元数据）是策展者写的，可以修改。

完整规范见 `docs/条目格式规范.md`。

## 怎么用

- **找提示词**：打开 `INDEX.md`，按分类浏览，点标题跳到条目。
- **程序或 AI 检索**：读取 `index.jsonl`，按「分类」「标签」「适用模型」「核对状态」过滤；「原文」字段就是可直接使用的提示词。
- **学写法**：先读 `docs/最佳实践.md` 和 `docs/术语速查.md`，再看 `prompts/提示词写法/`、`prompts/运镜/42`、`prompts/运镜/41`（运镜词典）。
- **使用前**：看条目的「适用模型」（不同模型对时间戳、否定词的支持不同）和「核对状态」；把模板里的【】、`@图1`、`<<<image_N>>>` 等占位符换成实际内容。

## 维护

修改或新增条目后，在仓库根目录运行：

```
python3 scripts/build_index.py          # 重新生成索引与统计
python3 scripts/build_index.py --check  # 检查索引是否与 Markdown 同步
```
