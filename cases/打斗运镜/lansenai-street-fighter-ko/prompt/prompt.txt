严格使用参考图作为 T=0.00s 首帧 与角色视觉基准。锁定同一名男性格斗角色：黑色中长碎发遮眼，冷酷、压迫、带一点野性与反英雄气质，穿黑色破碎羽毛感外套、灰色内搭背心、黑色皮裤、黑色战靴、手套、腰间金属链条。人物不可换脸，不可换服装，不可改变整体黑暗街头格斗气质。首帧中角色低伏蹲姿必须成立，右拳或前方拳位缠绕紫白电流，像蓄势待发的街头格斗王者。
场景固定为 霓虹夜色下的破败街区 / 日式街头巷战场景，地面潮湿反光，背景有模糊路人、霓虹招牌、烟雾、碎石、破损墙体、街头灯光、空气灰尘与蒸汽。整体风格要有 拳皇 / 街霸式的格斗游戏镜头语言 + 电影级真实质感，不是纯横板游戏画面，而是将格斗游戏的动作节奏、招式设计、命中反馈、镜头夸张感，做成高规格真人感 / 3D动画感的技能纯享短片。
整支视频是 30秒连续不断的纯战斗技能展示。主角面对一名强力近战敌人，敌人可以是黑衣街头格斗家或肌肉感强的异能对手，不要太花，重点仍然是展示主角。敌人主要作用是承接连招、反击、被打飞、被压制、最后吃下终极大招。全片节奏必须持续高强度推进，不能站桩，不能空镜，不能发呆，每一秒都有明确攻击、防御、闪避、反击或技能释放。
动作设计要学习经典格斗游戏逻辑：
轻拳试探 → 近身压制 → 连续技 → 浮空追击 → 霸体对拼 → 能量爆发 → 超必杀终结。
主角战斗风格是：街头搏击 + 重拳重腿 + 肘击膝撞 + 突进连打 + 电流异能拳法。
动作必须非常帅，非常干脆，像职业格斗游戏角色的招式设计，而不是普通乱打。
每一段攻击都要有清晰的命中反馈：身体震动、衣物摆动、脸部偏移、碎石炸裂、地面裂纹、空气震荡、电流扩散。
特效体系锁定为：
紫白电流、深蓝紫雷弧、局部黑色气流、拳锋电爆、落地冲击裂纹、短暂拖尾残影。
所有特效都必须绑定拳脚与身体发力，不能无来源漂浮。
拳头打出时，电流先在小臂与拳锋聚集，再在命中瞬间炸开。
重击时附带：冲击帧、1~3帧白闪、局部画面拉扯、背景瞬间失焦再拉回。
超必杀时必须有：强烈的镜头推进、极近拳锋特写、连续冲击帧、爆发式闪帧、最后一击大范围电流轰鸣。
运镜学习格斗游戏与动作电影混合语言：
前半段多用 侧向跟拍 / 半环绕 / 低机位推进 / 中近景打击特写，让人联想到拳皇、街霸那种“对峙—切入—连段”的格斗镜头；
中段进入更凶狠的 贴身连打、腾空追击、镜头跟着人物穿插移动；
释放大招时镜头可以进入 超必杀视角：时间短暂压缩、镜头突然贴近面部与拳锋，再跟着主角突进，把敌人一路打穿街道。
结尾一定有 KO音效、KO字幕设计、胜利收势镜头。
30秒内容流程
0.00–2.50s｜起手蓄势 + 第一波突进
角色保持首帧蹲姿，拳头电流快速增强，地面出现细小电弧爬行。敌人从前方高速冲入。主角瞬间蹬地爆发，以极快前冲重拳正面迎击，第一拳直击对方腹部，第二拳上勾，第三下肘击接膝撞，开场就像格斗游戏抢攻成功。每次命中都出现强烈打击停顿、轻微白闪、冲击帧、地面震尘。
2.50–6.00s｜近身压制连段
主角贴身连打，不给敌人喘息：左直拳、右摆拳、低扫腿、回身肘击、前踏重拳，动作像经典格斗角色的基础连段。敌人尝试防守与后撤，但被持续压制。镜头以侧向跟拍和半环绕为主，突出拳拳到肉。电流在命中瞬间沿敌人身体短暂蔓延，衣服与头发被电击带起。
6.00–9.00s｜敌人反击 + 主角格挡反打
敌人突然以重拳或回旋踢反击。主角抬臂硬挡，电流在手臂与敌人攻击碰撞处炸开，插入夸张冲击帧。随后主角一个侧身闪躲接近身反制，用抓腕、拉身、顶膝、重拳把敌人再次打回节奏。这里要拍出类似街霸中“Counter / Punish Counter”的爽感。可以加入一记短暂慢镜头展示主角擦身闪开攻击，再瞬间恢复高速节奏。
9.00–12.50s｜浮空追击
主角一记重型升龙式电拳把敌人轰上半空。镜头迅速仰拍跟上。主角紧跟跃起，在空中连续两拳一脚，把敌人打得短暂停滞，然后一记下劈腿把敌人砸回地面。敌人落地瞬间地砖碎裂，尘土炸起。这里要有典型格斗游戏“launcher → air combo → slam down”的感觉。
12.50–16.00s｜街头位移连招 + 场景互动
主角落地后不等尘埃散去，瞬步突进继续压制。敌人从碎石中起身想反扑，主角用低位滑步躲过一击，然后贴地前冲，接回旋踢把敌人踢向一侧墙面。紧接着主角追上去，一记电流重拳把敌人轰在墙上，墙体裂开、碎石飞溅。镜头跟着敌人被打飞的轨迹拉过去，再迅速回切主角追击。
16.00–20.00s｜霸体对拼 + 能量升级
敌人进入强力爆发状态，正面冲回来与主角展开一次正面对拼。双方连续出拳、格挡、顶撞。主角拳上紫白电流越来越强，电弧从拳头蔓延到整条手臂，甚至在地面和空气中撕出细小裂闪。这里要有拳皇/街霸式“气槽已满”的感觉。命中和格挡都要加重冲击帧与闪帧。主角最后一记重拳将敌人强行打退数米，自己缓缓站稳，进入超必杀起手状态。
20.00–24.00s｜超必杀启动
主角压低身体，单拳收于腰侧，另一手前探，电流疯狂汇聚，四周灯光短暂闪灭，空气中出现不稳定雷弧。镜头给面部特写、拳锋特写、脚下电流裂纹特写。随后角色爆发式冲刺，像一道紫白电光直线撕开街道。进入超必杀镜头语言：背景拉长、画面轻微变暗，只有主角拳锋与电流极亮。主角对敌人打出高速多段冲拳，像瞬间几十拳连打，每拳都伴随电爆、冲击帧、闪帧和强烈的画面拉扯感。
24.00–27.50s｜终极一击
多段超必杀后，主角一把将敌人打到失衡，随后腾空转体，蓄全力打出最后一记终结重拳/电流炮拳。拳头命中时，爆发巨大的紫白电流冲击波，电弧像树枝般向四周疯狂炸开，整条街巷被瞬间照亮，地面裂出放射状裂纹，敌人被正面轰飞。这里必须有最强烈的一次：连续闪帧 + 强冲击帧 + 爆炸式电流扩散 + 夸张打击停顿。
27.50–30.00s｜KO收尾
敌人重重砸落，彻底失去战斗力。屏幕中央或偏前景出现极具设计感的巨大 “KO” 字幕，字体参考经典格斗游戏的粗壮能量字形，但更现代、更高级，带霓虹描边与轻微故障闪烁效果；同时响起清晰有力的 “K.O.!” 音效。随后镜头切回主角，他缓缓收势站定，拳上的电流逐渐消散，只剩零星电弧。最后给一个低机位英雄式收尾镜头，主角冷冷看向前方，呼吸平稳，仿佛整场战斗只是热身。
音效设计
全程加入高质量格斗游戏式音效：
重拳命中：厚重低频冲击 + 皮肉撞击声
电流技能：高压电弧噼啪声 + 能量聚集低鸣
破地、碎墙：石块炸裂声
冲击帧时强化低频轰鸣
超必杀阶段加入连续打击爆音
最后必须有清晰响亮、极具辨识度的 “K.O.!” 音效
字幕 / HUD / 设计效果
不是全程满屏UI，但可在关键时刻加入极少量格斗游戏式设计元素：
重击时短暂出现极小的 HIT / COUNTER / RUSH 风格动效字样，可非常克制
最后 KO 必须清楚、帅气、大字设计感强
KO字幕可以伴随一瞬的白闪、描边、电流抖动、故障感拖影
不要廉价游戏UI，不要复杂血条，重点是高级、简洁、像宣传片级格斗设计语言
