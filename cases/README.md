# Cases · 对照样例

每个样例一个子目录，尽量成套齐全，便于对比提示词和成片效果：

```
cases/<中文分类>/<slug>/
  prompt/prompt.txt  # 原提示词（逐字原文）
  character-card/    # 角色卡 / 定妆 / 参考图（如有）
  video/             # 成片或关键片段（大文件用外链清单）
  notes/             # 来源、模型、参数、对比说明
  MEDIA.md           # 成片来源与下载方式
  RESULT.md          # 提示词要点 ↔ 画面效果对照
```

原则：

- 本库只收提示词；已有成片的样例作为参考保留，不再要求新条目配成片。
- `prompt/prompt.txt` 是该提示词在库内的唯一正文副本（`prompts/` 下对应位置只留链接和元数据，避免重复）。
- 第三方素材只归档公开分享的内容，并在 `notes/` 写清来源链接。
- 样例也列在根目录 `INDEX.md` 末尾和 `index.jsonl`（`条目类型` 为 `case`）中。
