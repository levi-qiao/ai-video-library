## 3. 延长后的拼接点：前段删 6 帧、后段删 1 帧，并尽量在切镜处结尾

> 巧在哪（非原文）：延长出来的新片段和原片段接在一起时会跳一下或倒退，官方给了具体的删帧数，并建议把续写的起点放在一个切镜之后，让跳变藏在剪辑点里。

```
## 延长视频衔接处跳变

典型现象

使用视频延长功能生成新视频后，将新视频与原视频进行拼接，在衔接处可能出现画面跳变、回退的问题。

解决方案

当前建议通过后期剪辑修补，对齐关键帧，后续将依托模型迭代进行根本性优化。

1. 将待拼接的视频导入剪映或其他专业视频剪辑软件。

2. 在第一个衔接处，将前一段视频的末尾删减 6 帧。

3. 同时，将后一段视频的开头删减 1 帧。

4. 对所有的拼接点重复以上操作。

5. 导出并检查拼接后视频的流畅度。

说明

视频帧对齐后，仍可能存在细微跳变，建议在续写生成视频的时候以转场切镜的时刻结尾，下一段视频以结尾切镜后的新场景为起始。
```

## 4. 白模续写：先把视频转成白色 3D 模型，再拿去延长，减少画质劣化

> 巧在哪（非原文）：直接拿生成的视频续写，画质会一次比一次差（人脸尤其明显）。官方的办法是先把原视频转成纯白 3D 模型的「白模视频」，只保留结构和动作，再作为续写输入。

```
## 视频延长画质劣化

典型现象

将模型生成的视频作为输入素材进行延长续写时，会出现画质劣化。多次续写会叠加劣化效果，尤其人物人脸区域易出现斑驳色块。

解决方案

当前可通过以下方式缓解画质劣化，后续将依托模型迭代进行根本性优化：

1. 将原始视频通过 Seedance 2.0 转为白模视频，再作为续写输入素材。

   参考提示词：将视频转为白色 3D 模型，人物统一为纯白 3D 模型，无色彩、无纹理、无阴影，纯白背景，结构稳定、运动流畅。

2. 优先选用高清图片作为参考素材。

3. 合理控制视频续写次数，避免多次叠加续写。

## 5. 防「双胞胎」：人名后标注对应图片 + 结尾加全局约束，且不用三视图

> 巧在哪（非原文）：多人画面里突然出现两个一模一样的人，常见原因之一是用了三视图 / 多视图当参考——模型会把同一人的不同角度当成不同的人。

```
## 双胞胎问题

典型现象

在画面人物较多且传入人物三视图作为参考素材的场景下，生成视频同一画面中易出现两个完全相同的人物。

根因分析

* 提示词中对人物主体的定义不清晰，模型无法精准区分不同人物角色；

* 以人物三视图 / 多视图作为参考素材时，易造成模型人物识别混淆，从而生成重复同款人物。

解决方案

说明

目前无法直接做到 100% 避免双胞胎问题，只能通过以下方法降低其出现概率、提升抽卡成功率。

1. 明确人物主体关联

在提示词中清晰定义每个人物角色，明确角色与参考图的对应关系。建议在人物名称后标注对应参考图，并保持格式统一。

示例：张三（对应图片 1）将绿色存折扔向站立的李四（对应图片 2）。

2. 添加全局约束指令

在提示词末尾增加固定约束：视频全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果，同一画面中仅保留单个对应人物，不出现人物重复复刻。

3. 优化参考素材

人物参考图优先使用单人独立照片，不建议使用三视图、多视图素材。

4. 精简优化提示词

请勿直接将完整剧本作为提示词使用，文案内容过度冗余易造成模型理解混乱，需精简无关表述、保证指令清晰聚焦。

## 6. 人脸参考：单独一张大头照 + 一张全身照，不要多视图

> 巧在哪（非原文）：直觉上给的角度越多越像，官方却明确说多视图会被当成多个人，反而更容易「换脸」；更好的是大头照与全身照分开给，并把越需要精准参考的素材写得越靠前。

```
## 人脸参考不准确

典型现象

生成的角色形象与参考图不一致，或在视频中途发生“换脸”，导致视频中人物撞脸明星被审核拦截。

根因分析

人脸参考图的有效性不足

* 参考图混用：将人脸参考图与全身/半身姿态图、服装参考图、细节图等合并在同一张图片中提供给模型。

* 人脸占比过小：在混用参考图中，人脸区域占整张图的比例过小，模型在提取人脸特征时权重不够，容易被背景或其他元素干扰。

解决方案

强化人脸参考的独立性和权重：

1. 准备人脸特写图：在原有全身照之外，额外准备一张只包含角色头部的人脸特写图（大头照，仅保留面部，无表情最佳，尽量减少肩颈、背景等干扰元素）。

2. 提示词中主体定义清晰：<主体1> 的面部特征参考图片1（大头照），妆造参考图片2（全身照） 。

3. 重要素材前置：越需要精准参考的素材，放在提示词中越靠前的位置。

注意

人物参考使用大头照 + 全身照即可，不建议使用人物多视图。多视图素材包含同一人物的不同角度，模型易将其识别为多个不同主体，反而加剧人脸参考不准确的问题。
```

> 策展备注（非原文）：与本库 `人物卡/` 的三视图、多视图设定图并不冲突——那些是做角色资产的生图提示词；**拿去做 Seedance 2.0 视频参考时**，按本节改用大头照 + 全身照。

## 7. 不想要字幕：尽量横屏生成，再裁成竖屏

> 巧在哪（非原文）：官方观察到横屏出现「自带字幕」的概率明显低于竖屏，这是很少有人想到的出片参数选择。

```
## 视频中包含字幕

典型现象

提示词中未要求生成字幕，生成的视频中包含字幕。

解决方案

说明

目前无法直接做到 100% 避免生成字幕，只能通过以下方法降低其出现概率、提升抽卡成功率。

1. 在提示词中加入明确的约束指令：“保持无字幕”、“避免生成任何文字或字幕”。

2. 如果参考的图片/视频中包含的文字并非必要信息，建议先通过工具去除文字（例如使用 Seedream/ Seedance 模型的图片/视频编辑能力），再使用无文字素材作为输入。

3. 在业务允许的前提下，优先选择横屏尺寸生成视频（横屏生成字幕的概率明显低于竖屏），后续可通过剪辑软件裁剪为竖屏。

## 8. 参考人物超过 4 个：先分组生成合照，再用合照生成视频

> 巧在哪（非原文）：8 个角色直接丢进去会多人、少人或重复；先分两组各出一张合照，再用合照做参考。

## 参考人物过多

典型现象

当参考人物数量超过 4 人时，模型输出稳定性下降，生成的视频可能出现人物数量不符（如少人、多人）或人物重复等问题。

解决方案

当前可通过以下方式缓解，后续将依托模型迭代进行根本性优化：

1. 分步生成图片：将人物分组，确保每组生成的图片中人物数量不超过 4 人。例如，6 个人可分成 2 组，每组 3 人，分别生成图片。

2. 图片生成视频：使用第一步生成的多张分组图片作为参考素材，再生成最终视频。
```

## 9. 文字说不清的特效：直接给一段参考视频

> 巧在哪（非原文）：倒计时、数字滚动这类有严格逻辑的动效，文字描述常常乱跳；把目标特效的视频作为参考素材，比加形容词有效。

```
## 特效效果不符合预期

典型现象

通过提示词文字描述特定特效时，可能会出现特效效果与预期不符的情况，例如：提示词指定「数字“2999”以倒计时动画出场」，实际生成的数字滚动特效出现无序跳变，不符合标准倒计时逻辑。

解决方案

建议采用参考视频定义特效：将目标特效视频作为参考素材输入模型，让模型精准理解特效形态与运动逻辑，生成效果更贴合预期。例如：数字“2999”出场方式参考视频1。
```

## 10. 台词读错字：换成读音相同的常用字

> 巧在哪（非原文）：模型配音会读错多音字、生僻字、形近字；官方办法是在提示词台词里直接换成同音常用字（只影响读音，画面文字另写）。

```
## 中文发音不准

典型现象

模型对多音字、生僻字、形近字容易读错。

解决方案

可将易读错文字替换为发音一致的常用同音字，规避发音偏差，还原预期音频效果。注意该方案仅为优化手段，无法完全规避所有发音问题。

示例：可将提示词中“螭龙山”改写为同音字“吃龙山”。
```

> 策展备注（非原文）：如果同一句台词还要作为画面字幕显示，同音字会被写到画面上；这时台词和字幕要分开写（SD2.0 约定 {} 为台词、【】为字幕）。

## 总结（非原文）

这份官方指南里最值得记住的，是几条「反直觉」的经验：

- **生成方式**：延长可以往前补（§2），两段视频之间可以让模型只补中间（§1）。
- **拼接与续写**：拼接点前段删 6 帧、后段删 1 帧，最好把续写起点放在切镜之后（§3）；多次续写前先转白模（§4）。
- **参考素材**：人脸用大头照 + 全身照，不用三视图 / 多视图（§5、§6）；超过 4 人先分组出合照（§8）；复杂特效直接给参考视频（§9）。
- **出片参数与音频**：想少出字幕就横屏生成再裁（§7）；读错的字换同音常用字（§10）。

以上都是 Seedance 2.0 官方针对自家模型的说明，换用其他模型时不一定成立（例如 Runway Gen-4 官方不支持否定写法）。
