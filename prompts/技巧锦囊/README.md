# 技巧锦囊

给「想不到要问」的人准备的分类：收录**不显眼、但能给人新思路的技巧**，例如用力场让特效和画面融合、用一镜到底拍打斗、用混合风格做出电影感等。适合没有具体目标时主动翻看、找灵感。

## 两种收录方式

1. **主分类在这里**：以技巧本身为主要看点的新条目，文件直接放在 `prompts/技巧锦囊/`，格式与其他分类相同（见 `../../docs/条目格式规范.md`）。
2. **交叉收录**：条目留在原来的主分类，只在元数据里加标签 `技巧锦囊`，并填写两个字段：
   - `技巧钩子`：一句话说清这条的巧思（为什么值得看）。
   - `触发场景`：什么情况下会想用到它。

两种条目都会出现在根目录 `INDEX.md` 最上方的「技巧锦囊」一节和 `index.jsonl` 中（`标签` 含 `技巧锦囊`）。
