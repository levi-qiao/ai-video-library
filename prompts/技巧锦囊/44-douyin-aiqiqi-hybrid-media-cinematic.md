## 3. 核对与冲突（非原文）

1. **术语核对。** 「丁达尔效应」严格说是胶体中微粒对光的散射（https://en.wikipedia.org/wiki/Tyndall_effect ），提示词里被借用来指「看得见的光柱」，与本库 `docs/术语速查.md`「体积光 / 丁达尔光」的用法一致；「环境遮蔽」即 ambient occlusion，是计算每个点被周围几何体遮挡多少环境光、让缝隙和接触处变暗的渲染技术（https://en.wikipedia.org/wiki/Ambient_occlusion ），§2.4 里「接触面有精准的环境遮蔽阴影」用的正是这个意思；「飞白」「漏光」见 B、C 的备注。
2. **作者的机制说法未经证实。** 口播「AI会把人物和背景当成两个图层来处理」是作者的比喻：即梦 / Seedance 官方文档没有「图层」这种机制说明，本库不采信为事实。可以确认的只是：在提示词里写明媒介和风格会影响结果——火山引擎 Seedance 2.0 官方指南「风格漂移」一节也建议「在提示词中加入明确的风格约束词」（https://www.volcengine.com/docs/ark/seedance-2-0-prompt-guide ）。
3. **评论区的反对意见。** 点赞最高的评论（168 赞）说「人家风格是Mj出来的，视频模型仅靠提示词是出不来这种风格」，另有评论「还是要mj先抽卡，这样才能省token」（23 赞）。视频画面用的是「全能参考」模式（可以上传参考图），开头那些「大神作品」怎么生成的，视频没有交代；A、B、C 三段后面的成片是否只靠这段文字生成也无法从视频证明。**所以把这三段当作「风格方向词」来用，想稳定复现某种画风，仍建议先出参考图再图生视频**（与 SD2.0 官方「将参考图先变为目标风格再进行生视频」一致）。
4. **库内去重。** 全库检索「混合媒介」「实拍背景叠加」「16mm」「漏光」「VHS」：无重复条目。`国风古装/11` 有一条用「2D手绘赛璐璐 + 水墨飞白」的完整武侠提示词，与本条 B 段是「方法 vs 实例」的关系，不合并。

## 总结（非原文）

这条视频讲的是一个很少有人想到要问的点：**画面「烂大街」往往不是模型不行，而是提示词只写了题材（「女修站在竹林」），没写媒介。** 作者的办法是在提示词里明确写出「A 媒介叠加 B 媒介」，并说清两者怎么对齐：

- **实拍 + CG**：写「实拍背景叠加 CG 角色」，再补一句让两层对齐的条件（光照匹配、景深同步、运动模糊一致、接触面有阴影）。对齐条件是关键，否则容易像抠图。
- **3D + 2D**：主体保持 3D 写实，只把特效换成 2D 手绘（水墨晕染、飞白笔触），再写「与写实渲染形成对比」，让模型保留反差而不是把两者糊成一种。
- **数字 + 模拟**：高清数字画面叠加胶片漏光、VHS 噪点、高光溢出，让画面有年代感。

**可复用模板（策展者整理，非原文）：**

```
[A 媒介]叠加[B 媒介]，[A 负责的部分]作为[背景 / 主体]，[B 负责的部分]采用[B 的具体质感]，[两层怎么对齐：光照 / 景深 / 阴影 / 运动模糊 / 色调]，与[A 的质感]形成对比
```

- 组合灵感可以直接用 §2.3 的 29 个小标题（实拍 × CG、3D × 2D、照片 × 三维、数字 × 模拟、AI × 手工）。
- 注意 §3 第 3 条：想要稳定画风，先用参考图定调，再用这类媒介词加强。
