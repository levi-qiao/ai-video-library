### 覆盖哪些武器和招式

基本是「刺 / 挑撩 / 横扫斩 / 格挡」四类动作在不同兵器上各写一遍，仙侠和唐刀两组换成招式名，加了镜头和环境。

### 共同结构

作者在图 4 自己给了公式：**角色 + 动作 + 发力方式 + 受力反馈 + 画面张力 + 镜头语言 + 环境氛围 + 细节质感**。其他四张图没写标签，但也按这个顺序写：

1. **角色 + 动作**：「古装武者双手持长枪向前突刺」，一句话交代谁、拿什么、做什么动作。
2. **发力链**：从脚到兵器逐节写，例如「前脚跨步落地，后脚猛蹬、腰胯拧转、送肩推枪」。仙侠组直接用箭头：「下盘发力→腰胯拧转→肩胛展开→手臂上抬→手腕压剑→剑尖冲天」。
3. **兵器受力反馈**：枪身弯曲、震颤、回弹；碰撞迸出火星；剑身清鸣。
4. **身体与环境反馈**：衣摆、发丝被甩开，尘土、碎石、水花飞溅，脚底后滑犁开泥土，对手后仰或被挑飞。
5. **画面张力 / 感受词**收尾：「直线穿透感与扑面冲击力」「上扬爆发、挑飞感和瞬间失重感」「硬碰硬的重量感与反作用力」。
6. **镜头语言**（仙侠、唐刀两组才有）：低机位仰拍、侧面跟拍、360 度环绕、俯瞰、高速跟拍 + 拉近特写。

分号「；」常把「身体怎么发力」和「力传出去以后世界怎么反应」隔成前后两段。

### 为什么有效

- **写因果，不写形容词**。模型对「很帅、很炫」没有稳定的执行方式，但「后脚猛蹬 → 腰胯拧转 → 送肩推枪」给出了身体各部分的先后顺序，动作更连贯，更少出现手臂单独甩动的「假打」。这正是作者在图 4「错误示例 vs 优化思路」里对比的点。
- **受力反馈让打击有重量**。兵器弯曲回弹、脚底滑出、泥土被犁开、衣袖被反震带动，这些次级运动让观众相信力是真的传过去了。
- **同一动作类型换兵器复用**。刺、挑、扫、格四类动作的发力链大体相同，换兵器只改兵器细节和反馈，方便批量做武戏分镜。
- **镜头与动作方向配对**：上挑、劈天配仰拍，环绕旋斩配环绕运镜，突刺配高速跟拍 + 特写，镜头运动顺着力的方向走。
