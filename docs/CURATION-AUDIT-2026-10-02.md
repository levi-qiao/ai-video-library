把“条目越多越好”改成“核心库越准越好”。本轮以 **独特知识量、可执行性、来源质量、核验状态、检索噪声** 为主要标准。

## 结果

- 体检前：397 条计数 Prompt。
- 核心 Prompt：217 条。
- reference：138 条（保留原文，但不参与核心 Prompt 计数和默认混排）。
- cases：17 个成片对照。
- 删除：45 条低价值聚合转载 Prompt，涉及 28 个 Markdown 文件。

## 删除标准

本轮删除的是第三方聚合来源中的低信息密度条目，主要来自 FreyaVideo、ATLabs、Memons、AniKuku、Seedance22。不是因为“第三方一定差”，而是这些条目在本库中同时表现为：

1. 多为短模板或场景换皮；
2. 与官方指南、作者原帖、已保留高质量案例功能重叠；
3. 对可复用方法没有新增结构；
4. 来源权威性低于官方/原作者；
5. 留在核心索引会增加搜索噪声。

本轮没有按“短”一个条件自动删除；短而权威的官方示例进入 reference。

## 为什么不继续硬删

剩余 217 条中仍存在“同题材、不同写法”的相似案例，但没有发现可以仅凭文本近似就安全判定为重复的大片重复组。下一步若继续瘦身，应做**语义级人工策展**：同一能力只保留代表作，其他条目要先确认没有独特动作、镜头、转场、特效或模型语法，再合并/删除。

## 核心库使用原则

默认检索顺序：

1. TEMPLATES / PLAYBOOK；
2. 217 条核心 Prompt；
3. reference；
4. cases / 原始出处。

核心 Prompt 的意义是“值得拿来直接生成、改写或拆解”；reference 的意义是“值得查，但不该抢主索引注意力”。


## 第二阶段：语义核心化

第一阶段的 217 条仍混有“可查组件”和“完整作品”。第二阶段不再按来源删内容，而按使用形态分层。

进一步降级为 reference 共 66 条：孔明兵器动作词典 20 条；两份网页打斗示例合集 16 条；人物卡组件 11 条；修画质组件 11 条；社区方法摘录 6 条；特效渲染术语 2 条。

第二阶段结果：核心 Prompt **151**，reference **204**，cases **17**。打斗运镜核心从第一阶段前的 59 条降至 23；人物卡 13→2；生图修画质 11→0。这里的“0 核心”不代表分类没价值，而是当前材料主要是拼装组件，仍完整保存在 reference。

151 条已经从“收藏数量”转向“作品/方法代表性”。剩余完整 Prompt 即使题材相近，往往仍有不同的时序、参考素材、声音、动作、镜头或叙事结构。下一阶段应做代表作优先级，而不是继续按相似度硬删。


## 第三阶段：能力图谱，不再减量

151 条核心不继续按相似度硬砍。新增 `CAPABILITIES.md`，把案例中的可迁移价值规范化为结构、动作、镜头、节奏、转场、世界反馈、特效、表演、空间、产品、UGC 等能力族。

核心改变：检索从“找最像的旧 Prompt”改成“选 3–5 个能力 + 1 个主母版 + reference 补词 + 按模型重写”。四则水墨武戏被拆成可复用能力，而不是继续复制其完整风格段。

约束：能力名只用于检索/规划，最终 Prompt 必须翻译成具体动作、镜头与反馈；单次默认 3–5 个能力，防止能力标签再次变成关键词堆砌。
