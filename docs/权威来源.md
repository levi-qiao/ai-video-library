## 1. 判断规则（日常收录与审核都用这套）

1. **先看目标模型自己的官方文档。** 条目标注了适用模型的，用该模型厂商的文档判断；某条写法在 A 模型官方推荐、在 B 模型官方不支持，是「模型相关」，不是对错问题，在元数据里写清楚适用范围。
2. **没有标注模型的通用写法，用多家官方文档的共识判断。** 共识见 `docs/最佳实践.md`、`docs/首尾帧工作流.md`；只有一家说、别家没说的，写成「X 官方建议」，不要写成通用规则。
3. **与目标模型官方文档直接矛盾的技巧说法**（例如在官方明确不支持负面提示的模型上教人写负面词），在条目「备注」里标注矛盾与出处；若该条目的价值只在这个错误说法上，移出计数并记入 MANIFEST。**作者原文一律不改。**
4. **注水 / 标题党的判断标准：** 官方文档普遍要求写清主体、动作、场景、镜头、光线等可见细节（Seedream：「主体 + 行为 + 环境」；Runway：「descriptive, not conversational or command-based」；BFL："Specific detail helps. Filler hurts."）。只有题材设定 + 形容词、没有任何可执行细节的条目，按注水处理。
5. **旧版 / 已下线的功能**（见第 3 节）保留为历史参考，但必须在元数据里标注「旧版」或「已下线」，不能当成现行写法推荐。
6. **影视术语**（景别、运镜、布光）以 `docs/术语速查.md` 列出的影视资料（StudioBinder、中文影视教材）为准；模型官方词表另有说法时，写提示词按模型官方词表。
7. **社区文章、第三方教程、聚合站不算权威。** 可以收录其提示词原文，但其中的「技巧结论」要标「社区说法」，与官方矛盾时以官方为准。
