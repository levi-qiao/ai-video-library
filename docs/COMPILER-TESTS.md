# PROMPT COMPILER · 回归测试

> 用这些需求检查 Compiler 是否真的“组合能力”，而不是检索旧 Prompt 换皮。

| 输入 | 应命中的核心能力 | 必须避免 |
|---|---|---|
| 竹林双刀战，别站桩，水墨自然 | 地形路线、借地形换位、接触—受力链、遮挡揭示、轨迹锚定 | 抄竹林原文；悬空水墨 |
| 打斗没力量 | 发力链、接触—受力链、接触点优先 | 只加“猛烈/震撼” |
| 一秒好几下，瞬冲拖尾，粒子炸但招招有接触感 | 超速交击、攻防即反攻、瞬冲换位、轻/重/终结分级、轨迹锚定 | 套 1–2 招慢展示；只加 fast；镜头和武器一起乱甩；每击都全屏大爆 |
| 大招不够炸 | 轻重终结分级、接触后短停、爆发后降频、结构破坏链 | 从第一秒全开；结果镜头缺失 |
| 镜头太乱 | 单一主运镜、接触点优先 | 同镜堆 orbit/whip/dolly/crane |
| 产品广告不高级 | 英雄物保持、功能→结果、材质光 | 只堆 luxury/cinematic |
| 手机 Vlog 太像广告 | 事件优先、手持不完美 | 完美轨道运动；随机乱抖 |
| 图生视频人物老变 | 主体锁、只写运动、输入图静态信息少重复 | 重写外貌导致漂移 |
| 两个人总像双胞胎 | A/B 身份锁、距离/接触锁 | 只写“两个不同的人” |
| 特效像贴纸 | 真实触发源、轨迹锚定、空气/粒子反馈 | 无触发悬浮粒子 |
| 追逐没有空间感 | 连续追击、地形路线、首帧占位 | 每镜换地点且无连续关系 |

## 通过条件

1. 默认能力数 3–5；超过 5 必须有明确理由。
2. 最终 Prompt 不直接罗列能力名。
3. 每镜只有一个主运镜意图。
4. 武戏关键命中能读出发力、接触和受力。
5. 环境变化跨镜保持。
6. 模型未知时不伪造精确语法。
7. 用户只要成品时，不展示冗长编译过程。
8. 代表母版只借结构，不复制人物、剧情和整段措辞。
