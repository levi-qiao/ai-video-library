# Open-source / license tags used in this archive

These tags appear in prompt file headers and curation notes. They describe **how the source was shared**, not a claim that this repo owns the text.

| Tag | Meaning |
|-----|---------|
| `CC-BY-4.0 (HF GokuScraper/seedance-2-prompts-datasets)` | Prompt+metadata redistributed by the Hugging Face dataset under Creative Commons Attribution 4.0. Attribute the dataset and, where known, the original author / `sourceLink`. |
| `author-shared-for-learning; copyright-retained` | Author posted the full prompt publicly (e.g. X/@lansenai, apimodels credited posts) for community learning/remix. **Copyright stays with the author**; not an OSI grant. |
| `unknown / blog copy-ready template; copyright retained` | Marketing/docs site published a pasteable template. Usable for learning; do not assume commercial relicensing rights. |
| `unknown` | Source public but license not stated. Cite URL; do not invent a license. |
| `MIT (repo scaffolding only)` | Applies to this repository’s own docs/structure (`LICENSE`), **not** to third-party prompt text or media. |

## Rules followed

1. **No invented prompts** — every archived prompt is copied from a cited public URL or dataset field.
2. **Cite source URL** on every entry.
3. **Prefer high-engagement / high-structure** (likes/views/stars when available; else featured flag, length, timed beats, constraints).
4. Video download / MEDIA packaging is **out of scope** for the current pass (prompt-only).
