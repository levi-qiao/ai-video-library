# Community Method Router

Read `AGENTS.md` first. Community methods are optional patches, never the repository's top authority.

## Authority

`target-model official guidance > docs/最佳实践.md rulings > verified source material > community method > inference`.

## Route

- canonical model ruling → `docs/最佳实践.md`
- first/last frame → `docs/首尾帧工作流.md`
- community synthesis → `prompts/技巧锦囊/46-hell-grind-cinedance-acting-lira-synthesis.md`
- general compiler → `COMPILER.md`
- spatial/action capabilities → `CAPABILITIES.md`

Use the community synthesis only for the incremental technique the task needs: measurable blocking, first-frame occupancy, camera-side locks, behavior under pressure, eye life, state-based acting, or image-specific LIRA concepts.

Do not copy full external skill bodies into this repository and do not promote community rules to universal model laws.

## Output

Integrate only the useful patch into the final prompt/workflow. Keep provenance/uncertainty explicit when explaining it.
